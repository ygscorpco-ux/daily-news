카드뉴스 관리자 업로드

ZIP 파일을 올리면 파일명에서 날짜/순번을 읽어 카드 세트를 자동 정리하고, 시트 입력용 TSV를 만듭니다.

1) ZIP 업로드

지원 파일명 예시 - 2026-03-10_1.png - 20260310-2.jpg - 2026-03-10/3.webp - card_2026.03.10_4.png

ZIP 파일을 선택해 주세요.

2) 제목 매핑 (선택)

형식: 한 줄에 `날짜,제목` 또는 `날짜[TAB]제목` 예시: 2026-03-10,사장님이 바로 쓰는 재방문 문구 5선 2026-03-11,배달앱 별점 방어 응답 템플릿

3) 자동 분류 결과

아직 분석 전입니다.

              

                

                  
                    

                      date
                      이미지 수
                      title (수정 가능)
                      img1~img6 경로
                    

                  
                  
                    
데이터 없음

                  
                

              

            


            

              
4) 출력

              

                
                
                
              

              
정리 ZIP에는 아래 파일이 포함됩니다.
- customer/images/YYYY-MM-DD/1.ext ... n.ext
- news.tsv (시트 붙여넣기용)
- news.json (백업용)

              
아직 생성 전입니다.

              
운영 팁: 정리 ZIP을 푼 뒤 `customer/images/`를 덮어쓰고, `news.tsv` 내용을 시트에 붙여넣으면 됩니다.
